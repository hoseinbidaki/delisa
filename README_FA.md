# DELISA — نسخه اولیه فروشگاه مینیمال فارسی

یک فروشگاه **راست‌به‌چپ، سبک و قابل اجرا روی لپ‌تاپ** با بک‌اند کاملاً Python و فرانت HTML/CSS/JavaScript خالص. هیچ فریم‌ورک فرانت، npm، React، Node.js، Bootstrap یا نصب پکیج Python برای اجرای محلی لازم نیست.

> **مهم:** این نسخه برای طراحی، توسعه مشترک و آزمایش جریان خرید است، نه فروش واقعی. درگاه بانکی، پیامک، محاسبه هزینه ارسال و یکپارچه‌سازی عملیاتی هنوز متصل نیستند. سفارش‌های ثبت‌شده «آزمایشی» هستند و وجهی دریافت نمی‌شود. تصویرهای اولیه SVG هستند، عکس واقعی محصول نیستند.

## راه‌اندازی در macOS یا Linux

۱. Python **3.10 یا جدیدتر** باید نصب باشد (`python3 --version`).

۲. ZIP را Extract کن و در Terminal وارد پوشه `delisa_starter` شو:

```bash
cd /path/to/delisa_starter
python3 app.py init-db
python3 app.py seed-demo
python3 app.py create-admin
python3 app.py run
```

دستور `create-admin` ایمیل، نام و رمز مدیر را می‌پرسد. هنگام تایپ رمز در Terminal چیزی نمایش داده نمی‌شود؛ این رفتار طبیعی است. رمز مدیر حداقل ۱۲ کاراکتر باشد. ایمیل و رمز از پیش تعیین‌شده در پروژه وجود ندارند.

آدرس‌ها:

- فروشگاه: **http://127.0.0.1:8000/**
- محصولات: **http://127.0.0.1:8000/shop**
- عضویت مشتری: **http://127.0.0.1:8000/register**
- ورود مدیر و مشتری: **http://127.0.0.1:8000/login**
- پنل مدیریت (بعد از ورود با حساب مدیر): **http://127.0.0.1:8000/admin**

برای توقف: `Ctrl + C`. برای اجرای مجدد فقط `python3 app.py run` لازم است؛ اطلاعات در دیتابیس باقی می‌مانند. `seed-demo` را دوباره اجرا کنی محصولات یکسان تکرار نمی‌شوند.

## Windows

در PowerShell، بعد از Extract و رفتن به پوشه پروژه:

```powershell
py -3 app.py init-db
py -3 app.py seed-demo
py -3 app.py create-admin
py -3 app.py run
```

اگر دستور `py` شناخته نشد ولی Python نصب است از `python` به‌جای `py -3` استفاده کن.

## روش کار در پنل مدیر

با حساب مدیر وارد شو؛ به `/admin` برو. امکانات شامل:

- **داشبورد:** بازدید صفحات، نشست مرورگرهای یکتا، سفارش‌ها، کاربران، موجودی کم، نمودار هفت‌روزه و صفحه‌های پربازدید.
- **محصولات:** افزودن، ویرایش، قیمت/قیمت قبلی، دسته‌بندی، موجودی، توضیحات، آپلود عکس JPG/PNG/WebP تا ۵ مگابایت، آرشیو/بازگردانی محصول. برای جلوگیری از شکستن سفارش‌های قدیمی، حذف محصول به صورت آرشیو انجام می‌شود.
- **سفارش‌ها:** فهرست سفارش‌ها، تغییر وضعیت، خروجی CSV. با لغو سفارشی که هنوز تحویل نشده، موجودی یک بار برمی‌گردد؛ سفارش لغوشده دوباره فعال نمی‌شود.
- **کاربران:** مشاهده حساب‌ها، نقش و تعداد سفارش.
- **نظرات:** نظرات مشتری فقط پس از تأیید مدیر روی سایت نمایش داده می‌شوند.

## حساب مشتری و خرید آزمایشی

مشتری می‌تواند عضو شود، وارد شود، جست‌وجو کند، محصول ذخیره کند، سبد خرید داشته باشد و با آدرس و موبایل سفارش آزمایشی ثبت کند. با ثبت سفارش، موجودی از دیتابیس کم می‌شود و یک سفارش با وضعیت «در انتظار بررسی» به وجود می‌آید.

**نکته:** سبد خرید به نشست مرورگر متصل است؛ پس از ورود همان سبد حفظ می‌شود. در نسخه اولیه، سبد به‌طور خودکار میان دو دستگاه مختلف همگام‌سازی نمی‌شود.

## ساختار پروژه

```text
delisa_starter/
├── app.py                   # سرور Python / API / احراز هویت / مدیریت / دیتابیس
├── templates/              # قالب‌های HTML ساده
├── static/
│   ├── css/style.css       # استایل اختصاصی RTL و Responsive
│   ├── js/app.js           # ناوبری نرم + جست‌وجو + سبد کشویی
│   ├── img/                # تصویرسازی سبک نمونه، مستقل از اینترنت
│   └── uploads/            # عکس‌های محصولات بارگذاری‌شده
├── tests/test_app.py       # تست‌های خودکار، بدون پکیج اضافی
├── generate_art.py         # بازتولید تصویرسازی‌های نمونه
└── README_FA.md
```

فایل دیتابیس خودکار در `data/delisa.sqlite3` ساخته می‌شود و **داخل ZIP اولیه قرار داده نشده**. گذرواژه هیچ مدیر آماده‌ای در پروژه وجود ندارد.

## «مثل اپ» اما سبک؛ Refresh هم سالم

صفحه اصلی، Shop و Product از سرور به صورت HTML آماده می‌آیند؛ بنابراین لینک مستقیم، Refresh و نمایش اولیه محتوا به جاوااسکریپت وابسته نیست. بعد از ورود، جاوااسکریپت داخلی فقط محتوای `<main>` را بدون رفرش کامل جایگزین می‌کند؛ Header و سبد خرید سر جای خود می‌مانند. آدرس مرورگر و دکمه‌های Back/Forward کار می‌کنند و جای اسکرول با History API بازیابی می‌شود. بعضی مسیرهای احراز هویت عمداً ریدایرکت کامل دارند.

تصاویر نمونه داخل پروژه‌اند؛ برای اجرای اولیه به اینترنت یا دانلود تصویر خارجی نیاز نیست. تصاویر واقعی محصول را بهتر است پیش از آپلود به WebP کم‌حجم تبدیل کنی. برنامه تصویر را **خودکار فشرده نمی‌کند**.

## پشتیبان‌گیری و نگهداری

```bash
python3 app.py backup-db
python3 app.py cleanup
```

بکاپ سازگار با SQLite در `data/backups/` ذخیره می‌شود. **پوشه `static/uploads/` را نیز جداگانه بکاپ بگیر**؛ فایل‌های تصاویر داخل دیتابیس نیستند. `cleanup` نشست‌های منقضی و بازدیدهای قدیمی‌تر از یک سال را حذف می‌کند. نگهداری بکاپ روی همان سرور در برابر خرابی کل سرور محافظت نمی‌کند؛ کپی بیرونی تهیه کن.

## نکات انتشار عمومی (قبل از فروش واقعی ضروری)

سرور داخلی Python (`python app.py run`) **برای توسعه محلی است، نه ارائه به مشتریان اینترنتی**. برای استقرار روی Linux با HTTPS باید از سرور WSGI تولیدی، Reverse Proxy، پشتیبان‌گیری خارج از سرور، محدودسازی درخواست و مانیتورینگ استفاده شود. اگر سرور Gunicorn نصب کرده‌ای:

```bash
# تنها در سرور Linux و در محیط استقرار؛ برای اجرا روی مک لازم نیست
pip install gunicorn
python3 app.py init-db
DELISA_SECURE_COOKIE=1 gunicorn --workers 2 --bind 127.0.0.1:8000 app:application
```

پشت Nginx یا Reverse Proxy با HTTPS راه‌اندازی کن؛ مقدار `DELISA_SECURE_COOKIE=1` را **فقط با HTTPS** بگذار. درخواست‌های `/static/` را در صورت امکان مستقیم با وب‌سرور/CDN سرو کن. برای ترافیک زیاد یا چند ماشین دیتابیس SQLite و ذخیره نشست و فایل محلی باید به معماری قوی‌تر مهاجرت کنند. از IP عمومی بدون HTTPS برای ورود مدیر استفاده نکن.

قبل از فروش واقعی همچنین به این موارد نیاز است: پرداخت و تأیید سمت سرور با وب‌هوک معتبر درگاه، سفارش‌گذاری و موجودی‌سنجی متصل به پرداخت، پیامک، سیاست حفظ حریم خصوصی، ضداسپم/نرخ‌دهی در پروکسی، لاگ و هشدار خطا، بهینه‌سازی واقعی عکس‌ها، قوانین مرجوعی/ارسال و تست امنیتی مستقل. سفارش آزمایشی این پروژه در لحظه ثبت، موجودی را کم می‌کند و **نباید بدون پیاده‌سازی وضعیت پرداخت به فروشگاه واقعی تبدیل شود**.

## تنظیمات

- آدرس و پورت محلی: `python3 app.py run --host 127.0.0.1 --port 8000`
- مسیر داده‌ها: متغیر محیطی `DELISA_DATA_DIR`
- Cookie امن زیر HTTPS: متغیر محیطی `DELISA_SECURE_COOKIE=1`
- فونت سیستم به جای فونت آنلاین استفاده شده تا هیچ درخواست خارجی اضافه ایجاد نشود. در نسخه نهایی می‌توان فونت قانونی برند را روی سرور خودت نصب کرد.
